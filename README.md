# Gammafunktion
Eulers Gammafunktion selbst erstellt um sie besser zu verstehen

## Fakultät berechnen

Das Konsolenprogramm mit Python 3 starten:

```sh
python3 fakultaet.py
```

Eine nichtnegative ganze Zahl eingeben, beispielsweise `5` für `5! = 120`.
Auch `0! = 1` wird unterstützt. Negative Zahlen und ungültige Eingaben
werden mit einer Fehlermeldung abgewiesen.

Die Berechnung multipliziert die Faktoren in einer Schleife, ohne eine
fertige Fakultätsfunktion zu verwenden. Pythons Ganzzahltyp `int` liefert
exakte Ergebnisse auch für große Zahlen (begrenzt durch Arbeitsspeicher
und Rechenzeit). Auch sehr große Ergebnisse werden vollständig ausgegeben.
